# MultiPC

Программа объединяет несколько компьютеров в локальной сети:

- **Одна клавиатура и мышь на все ПК.** Мониторы разных компьютеров выстраиваются в общую раскладку, курсор переходит с экрана одного ПК на экран другого через общую границу. Работают все подключённые клавиатуры и мыши: любой мышью на любом ПК управляется один общий курсор, а нажатия любой клавиатуры идут на тот ПК, где сейчас курсор.
- **Перенос окон.** Перетащите окно за край экрана к соседнему ПК (или выберите его в панели), и оно появится там. Программа продолжает работать на своём ПК, а на другом показывается её окно, которым можно пользоваться мышью и клавиатурой. Закройте окно там, и перенос закончится.
- **Передача файлов и папок** между компьютерами.
- **Общий буфер обмена**: текст и картинки, скопированные на одном ПК, вставляются на другом.

Полностью поддерживается Windows. Android (только файлы и буфер обмена, в том числе не в локальной сети) и сетевые диски будут следующими этапами, см. [план](#план).

## Как это устроено

- Каждый ПК запускает `multipc.exe`. Компьютеры находят друг друга широковещательными сообщениями в локальной сети (UDP 47800) и соединяются по TCP 47800.
- Все соединения зашифрованы (Noise `NNpsk0`: X25519, ChaCha20-Poly1305, BLAKE2s). Компьютеры одной группы знают общий ключ сопряжения; без него подключиться или прочитать трафик нельзя.
- Курсор принадлежит одному ПК в каждый момент. Когда он упирается в край экрана, за которым в раскладке стоит монитор другого ПК, курсор переходит туда, а местные мышь и клавиатура перехватываются и пересылаются на тот ПК. Окна при этом остаются на своих компьютерах: это общий курсор, а не единый рабочий стол. Пока курсор на другом ПК, на остальных он скрыт, а их клавиатуры и мыши тоже управляют тем ПК, где курсор.
- Перенесённое окно транслируется: его изображение снимается примерно 15 раз в секунду (`PrintWindow`, работает и для перекрытых окон), сжимается в JPEG и показывается на другом ПК, а клики и клавиши оттуда повторяются на исходном окне. Поэтому видео и игры в перенесённом окне идут с задержкой и меньшей частотой кадров.
- Нажатия передаются скан-кодами, поэтому на принимающем ПК действует его собственная раскладка клавиатуры.
- **Scroll Lock** возвращает курсор на компьютер, за которым вы сидите. Если компьютер с курсором отключился, ввод сам возвращается на местный ПК.

## Установка

1. Скачайте `multipc.exe` (артефакт `multipc-windows` в GitHub Actions) или соберите: `cargo build --release`.
2. Запустите `multipc.exe` на каждом ПК. Откроется панель управления http://127.0.0.1:47801. Окно программы не закрывайте.
3. В разделе «Устройства в сети» видны все ПК, где запущен MultiPC. Нажмите «Отправить запрос» у нужного ПК (или введите его IP-адрес).
4. На том ПК появится запрос с шестизначным кодом. Если код совпадает с кодом на вашем ПК, нажмите «Принять». После этого ПК в одной группе и соединяются сами, в том числе после перезапуска.
5. Перетащите компьютеры в «Расположении экранов» так, как стоят их мониторы. Раскладка сохраняется на всех ПК группы.

Если другой ПК не виден или запрос не доходит, нажмите «Разрешить в брандмауэре Windows» на обоих ПК: Windows по умолчанию блокирует входящие соединения в сетях, отмеченных как общедоступные.

Запрос на подключение передаётся по зашифрованному каналу, а совпадение кодов гарантирует, что между ПК никто не встрял. Принявший ПК передаёт ключ своей группы, и запросивший ПК переходит в неё.

## Команды

```
multipc                         запустить (то же, что multipc run)
multipc init [--key К] [--name И]  создать настройки; без --key создаётся новая группа
multipc key                     показать ключ сопряжения
multipc send --to ИМЯ путь...   отправить файлы или папки
multipc status                  компьютеры в сети и последние передачи
```

Полученные файлы сохраняются в `Загрузки\MultiPC`. Ход передачи виден в панели управления и в `multipc status`.

## Настройки

`%APPDATA%\MultiPC\config.toml`:

```toml
name = "ДОМ-ПК"            # имя компьютера в группе
key = "…"                  # ключ сопряжения, одинаковый на всех ПК
port = 47800               # порт для связи между ПК (TCP и UDP)
control_port = 47801       # порт панели управления, доступна только с этого ПК
peers = ["192.168.1.20"]   # адреса, к которым подключаться напрямую
download_dir = 'D:\Входящие' # куда сохранять файлы (по умолчанию Загрузки\MultiPC)
share_input = true
share_clipboard = true
open_panel = true          # открывать панель в браузере при запуске
```

Раскладка экранов хранится рядом, в `layout.toml`, и синхронизируется между ПК автоматически.

## Структура кода

- `crates/mpc-core` — общая часть без привязки к ОС: протокол, шифрование, геометрия раскладки, работа с путями файлов, настройки.
- `crates/multipc` — программа: сеть и обнаружение, движок общего курсора, передача файлов, буфер обмена, панель управления; `platform/windows.rs` — перехват (low-level hooks) и эмуляция (`SendInput`) ввода в Windows.

`cargo test` проверяет протокол, шифрование, раскладку, передачу файлов и логику перехода курсора (с поддельным драйвером ввода), на любой ОС.
